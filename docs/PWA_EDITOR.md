# Редактор карточек и PWA

## Панель администратора

Публичная часть сайта использует статические страницы GitHub Pages. Для редактирования каталога предусмотрена отдельная панель `admin.html`.

- Доступ к изменениям каталога разрешён только пользователям, внесённым в `public.admin_users`.
- Проверяйте название, категорию, город, адрес, координаты и источники перед сохранением.
- Дополнительные фотографии добавляйте только с подтверждённым источником и условиями использования.
- Ключ Supabase `service_role` нельзя помещать в HTML, JavaScript или репозиторий.

## PWA

Приложение использует `manifest.webmanifest` и `sw.js`.

- Страницы, CSS, JavaScript и локальные ресурсы кэшируются для повторного открытия.
- Каталог и маршруты обновляются из Supabase, а при недоступности сети используется встроенный каталог.
- Внешние фотографии и ранее загруженные тайлы карты могут быть доступны офлайн только после того, как браузер их закэшировал.
- Сторонние API, внешние ссылки и новые данные без сети не гарантируются.

## Установка

- Android / Chrome: откройте сайт по HTTPS и выберите «Установить приложение» в меню браузера.
- iPhone / Safari: «Поделиться» → «На экран Домой» → «Добавить».

## Публикация

1. Отправьте изменения в ветку `main`.
2. Дождитесь успешного workflow GitHub Pages в разделе Actions.
3. Откройте сайт по адресу GitHub Pages и обновите страницу с очисткой кэша при необходимости.

## Безопасность

Публичный publishable/anon key допустим в браузерном клиенте при корректно настроенных RLS-политиках. Секретные ключи и пароли должны храниться только в защищённых серверных секретах.
