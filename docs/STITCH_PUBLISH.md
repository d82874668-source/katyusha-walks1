# Публикация дизайна Google Stitch

Новая версия сайта на базе экспортированных экранов Google Stitch опубликована в основной ветке `main`.

Основные страницы: главная, каталог, интерактивная карта, карточка места, избранное, конструктор прогулок, редакционные маршруты и о проекте.

Данные и функции подключены через существующие модули проекта. Проверки JavaScript и структуры файлов проходят в GitHub Actions. Визуальная проверка выполняется после публикации в браузере.
