# Прогулки с Катюшей — UI design system

Версия: 1.0  
Назначение: единый визуальный и поведенческий стандарт для всех страниц сайта.

## Принципы
- Сохраняем редакционный, уютный характер городского гида: тёплая светлая поверхность, глубокий зелёный как основной цвет, терракотовый акцент, выразительные фотографии.
- Не копируем интерфейс другого продукта. Используем проверенные UX-паттерны, но сохраняем собственную визуальную идентичность.
- Одинаковые действия должны выглядеть и вести себя одинаково на главной, в каталоге, карте, карточке места, маршрутах и избранном.
- Mobile-first: сначала удобство на телефоне, затем расширение до планшета и десктопа.

## Инструментарий рабочего процесса
1. Figma — карта экранов, компоненты, варианты состояний и прототипирование.
2. GitHub — исходный код, история изменений, ревью и автоматическая проверка публикации.
3. Chrome DevTools — проверка реальных viewport, hit-testing, консоли, сети и производительности.
4. Lighthouse / PageSpeed Insights — производительность, доступность, SEO и best practices.
5. axe DevTools / WAVE — дополнительная проверка доступности; автоматические проверки дополняются ручными.
6. Playwright — повторяемые проверки ключевых пользовательских сценариев и размеров экранов.

## Design tokens
### Цвета
- Primary: #07241a — основной текст, ключевые действия.
- Primary container: #1e3a2f — основные кнопки и навигационные акценты.
- Secondary: #9d4229 — акцент, маркеры и важные состояния.
- Surface: #fbf9f5 — основной фон.
- Surface low: #f5f3ef — вторичные поверхности.
- Surface high: #eae8e4 — разделители и нейтральные панели.
- Outline: #727974 — вспомогательный текст и контуры.
- Error: #ba1a1a — ошибки; success и warning не должны различаться только цветом.

### Типографика
- Заголовки: Playfair Display.
- Основной текст и элементы интерфейса: Plus Jakarta Sans.
- Основной текст на телефоне: 16px или больше.
- Заголовки масштабируются через clamp(), строки не должны обрезаться.

### Сетка и интервалы
- Шаг отступов: 4px; базовые крупные интервалы кратны 8px.
- Desktop: до 12 колонок, Tablet: 8, Mobile: 4 или одна колонка в зависимости от содержимого.
- Контент не должен создавать горизонтальную прокрутку на ширине 320px.
- Карточки используют единый радиус и предсказуемые внутренние отступы.

### Адаптивность
- Mobile: до 767px; одна колонка для карточек, доступная нижняя навигация, компактная шапка, безопасные отступы для системных зон.
- Tablet: 768–1199px; промежуточная сетка и компактная навигация.
- Desktop: от 1200px; широкая сетка и полная навигация.
- Ключевые действия должны оставаться в пределах удобной зоны большого пальца.

## Компоненты и состояния
- Кнопки: primary, secondary, text, icon; default, hover, focus-visible, active, disabled, loading.
- Поля: label, placeholder, help text, error; размер текста ввода не менее 16px на телефоне.
- Карточки мест: фото, категория, город, адрес, краткое описание, рейтинг/цена, основные действия.
- Навигация: активная страница обозначается не только цветом; ссылки имеют понятные подписи.
- Карта: карта и список мест доступны как альтернативные способы выбора; маркеры не должны быть единственным способом открыть место.
- Уведомления: короткие подтверждения, ошибки с понятным следующим действием.
- Пустые состояния: объясняют, что произошло, и предлагают полезное действие.

## Доступность и сенсорное управление
- Цель для интерактивных элементов: 44–48 CSS px по высоте/ширине, где позволяет компоновка; минимум WCAG 2.2 AA — 24×24 CSS px либо достаточный интервал.
- Видимый focus-visible с контрастным контуром.
- Семантические кнопки и ссылки, доступные подписи для иконок.
- Не блокировать масштабирование страницы.
- Поддерживать prefers-reduced-motion.
- Нельзя перекрывать кликабельные элементы невидимыми слоями; проверять pointer-events и stacking contexts.

## Definition of Done для каждой страницы
- Проверены ширины 320, 360, 390, 768, 1024 и 1440px.
- Нет горизонтальной прокрутки и обрезанного текста.
- Все основные действия работают мышью, клавиатурой и касанием.
- Нет ошибок JavaScript в консоли и критических ошибок сети.
- Пройдены Lighthouse и axe/WAVE; замечания разобраны, а не просто проигнорированы.
- Проверены loading, empty, error и success states.
- Изменение прошло CI и реально опубликовано на GitHub Pages.
