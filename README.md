# Прогулки с Катюшей

Одностраничная платформа для поиска мест, впечатлений и планирования отдыха: четыре направления, интерактивная карта, подборки, галерея, личное избранное и история просмотров. Работает на GitHub Pages без сборки, данные хранятся в Supabase (необязательно: без него сайт использует встроенный список).

## Четыре направления

| Раздел | Что делает | Как работает |
|---|---|---|
| **Открой город** (`#discover`) | Достопримечательности выбранного города | Берёт места категорий `city, attraction, museum, exhibition, viewpoint, park, garden, square, embankment, beach, sea, trips`. Карточки крупнее, с большим фото |
| **Куда сходить** (`#venues`) | Заведения и развлечения | Остальные категории, сгруппированные в 11 фильтров: рестораны, кафе, кальянные, бары, бани и SPA, компьютерные клубы, ТЦ, кинотеатры, развлекательные центры, ночные клубы, боулинг. Сортировка по рейтингу, популярности и цене |
| **Спланируй прогулку** (`#planner`) | Ручной конструктор маршрута | Добавление мест (поиск или кнопка «В маршрут» на любой карточке), порядок кнопками и перетаскиванием, «Оптимизировать порядок» (ближайший сосед), пешком или на авто, расстояние и время по каждому участку, карта с нумерацией, сохранение, избранное, ссылка |
| **Мой идеальный день** (`#ideal`) | Автоматическая программа | 10 настроений, город, длительность, участники, бюджет, атмосфера, интересы. Результат: таймлайн со временем, фото, описанием, адресом, длительностью и ценой. «Другое место» заменяет одну остановку, «Другой вариант» пересобирает всё |

**Алгоритм «Идеального дня»** (`assets/js/ideal.js`, правила в `assets/js/taxonomy.js`): у каждого настроения есть сценарий из ролей (прогулка, красивое место, обед, культура, вечер и т. д.). Для каждой роли выбирается лучшее место по оценке: рейтинг, число отзывов, типичность категории для роли, приоритет достопримечательностей, атмосфера, выбранные интересы и близость к предыдущей точке. Однотипные места подряд и сети с одним названием штрафуются. Остановки добавляются, пока хватает времени. Если на какой-то этап в каталоге нет мест, сайт прямо об этом сообщает. Время в пути в программе дня оценивается по прямой ×1,3, а точные участки по дорогам считает планировщик (кнопка «В планировщик»).

**Сохранённые маршруты и ссылки.** Маршруты хранятся в браузере (localStorage). «Поделиться» создаёт ссылку вида `…/?plan=28,16,25&mode=walk&name=…#planner`: она содержит только номера мест, поэтому открывается на любом устройстве, где доступен тот же каталог. Для работы между устройствами каталог должен быть одинаковым: используйте Supabase.

Все пути относительные, поэтому сайт работает и по адресу `https://имя.github.io/репозиторий/`.

## 1. Публикация на GitHub Pages

1. **Создайте репозиторий.** На github.com нажмите **New repository**, назовите его, например, `katyusha-walks`, выберите **Public** (на бесплатном тарифе Pages работает только с публичными репозиториями) и нажмите **Create repository**.
2. **Загрузите проект.** Откройте репозиторий → **Add file → Upload files**, перетащите **содержимое** папки проекта (включая скрытый файл `.nojekyll` и папки `assets`, `supabase`, `tools`) и нажмите **Commit changes**. Через терминал:
   ```powershell
   git init
   git add .
   git commit -m "Первая версия"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/katyusha-walks.git
   git push -u origin main
   ```
3. **Включите Pages.** **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. **Получите ссылку.** Через 1–2 минуты вверху страницы Pages появится адрес `https://ВАШ_ЛОГИН.github.io/katyusha-walks/`. Отправьте его второму человеку.

Локальный просмотр (ES-модули не работают с `file://`):
```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
```

## 2. Подключение Supabase

1. **Создайте проект.** На supabase.com: **New project**, задайте имя, пароль базы и регион.
2. **Создайте таблицы.** **SQL Editor → New query**, вставьте весь `supabase/schema.sql` и нажмите **Run**.
3. **Заполните данными.** Новый запрос, вставьте `supabase/seed.sql`, **Run**.
   Для уже существующей базы сначала выполните `supabase/migrations/20261120_expand_places.sql`, затем `supabase/seed.sql`. Миграция только добавляет поля и индексы. Seed добавляет отсутствующие ID через `on conflict do nothing`: прежние места и маршруты не удаляются и не заменяются.
4. **Получите URL и ключ.** **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
5. **Подключите к сайту.** Откройте `assets/js/config.js` и впишите значения:
   ```js
   export const CONFIG = {
     SUPABASE_URL: "https://abcdefgh.supabase.co",
     SUPABASE_ANON_KEY: "eyJ...",
   };
   ```
   Закоммитьте файл. Через минуту сайт начнёт читать каталог и маршруты из базы. Избранное, история просмотров и сохранённые маршруты пока хранятся локально в браузере и не синхронизируются между устройствами. Это честно обозначено в разделе «Избранное».

> **Безопасность.** Ключ `anon` публичный по замыслу, на сайте его увидит любой. Публичный клиент использует Supabase для чтения каталога и маршрутов; личные данные пользователя в базе не хранятся. Избранное и история остаются в `localStorage`. Для безопасной синхронизации между устройствами сначала потребуется Supabase Auth и отдельные пользовательские таблицы с RLS-политиками, привязанными к `auth.uid()`. Никогда не вставляйте в сайт ключ `service_role`.

## 3. Обновление данных

Открывайте **Table Editor** в Supabase и редактируйте строки. Либо используйте SQL:

**Добавить место** (категория — slug из `CATEGORIES` в `tools/build_data.py`; новые проверенные записи добавляются в `tools/verified_places.json`, затем запускается генератор):
```sql
insert into public.places (title, description, category, latitude, longitude, image, rating)
values ('Кофейня у моря', 'Завтрак с видом на бульвар', 'city', 40.3665, 49.8490, 'https://example.com/photo.jpg', 4.8);
```
Координаты возьмите в Google Maps: правый клик по месту → первая строка с числами (широта, долгота).

**Добавить маршрут** (`places` — id мест по порядку остановок, id видны в таблице `places`):
```sql
insert into public.routes (title, description, places)
values ('Субботний вечер', 'Ужин и прогулка', array[16, 25, 9]);
```

**Изменить данные:**
```sql
update public.places set rating = 4.9, image = 'https://...' where title = 'Белый город';
update public.places set latitude = 40.3801, longitude = 49.8602, is_approx = false where id = 3;
delete from public.places where id = 12;
```

Новая **категория** требует строки в `CATEGORIES` в `tools/build_data.py` (название, иконка, оттенок), затем `python3 tools/build_data.py` и коммит `assets/js/data.js`.

**Важно про координаты.** Для мест с `is_approx = true` позиция на карте ориентировочная (район, а не точный адрес), а Google Maps ищет их по названию. Проверьте их по своим закладкам и поставьте `is_approx = false`.

## Используемые библиотеки

| Библиотека / сервис | Версия | Назначение |
|---|---|---|
| [Leaflet](https://leafletjs.com) | 1.9.4 (unpkg, SRI) | карта |
| OpenStreetMap | — | тайлы и данные карты |
| [OSRM](https://project-osrm.org) | демо-сервер | расстояние, время, линия маршрута на авто |

Сборщик не нужен: чистые HTML5, CSS3 и JavaScript ES-модули. Иконки встроены SVG-спрайтом.

## Заметки

- **После обновления выполните `supabase/seed.sql` ещё раз.** Он добавляет только отсутствующие записи (6 новых достопримечательностей Баку: Старый город, Дворец Ширваншахов, Башни Пламени, Приморский бульвар, Маленькая Венеция, Площадь Фонтанов). Если Supabase подключён, сайт показывает данные из базы, а не из `data.js`.
- **Фото, рейтинги и цены** для новых достопримечательностей намеренно пустые: выдумывать их нельзя. Заполните колонки `image`, `rating`, `price_min`, `price_max`, `price_unit` в Supabase.
- **В Баку пока нет ресторанов, кафе, баров, ТЦ и кинотеатров.** Фильтры для них есть, но пустые, а «Идеальный день» честно пишет, каких этапов не хватает. Добавляйте такие места в `places` с городом `Баку`.
- Пешие маршруты считает сервер FOSSGIS (`routing.openstreetmap.de`), автомобильные демо-сервер OSRM. Если сервис недоступен, показывается оценка со знаком «≈».
- Если данные Supabase не загружаются, откройте консоль браузера: сайт при этом работает на встроенных данных (статус виден в «Избранном»). `SUPABASE_URL` должен быть вида `https://xxxx.supabase.co`, без `/rest/v1/`.
- Демо-сервер OSRM не рассчитан на большую нагрузку. Для двоих этого достаточно; при сбое сайт покажет маршрут прямой линией.
- Расстояние считается от площади Фонтанов или от вас, если нажать «Моё местоположение» на карте (браузер спросит разрешение).
- Тайлы `tile.openstreetmap.org` подходят для личного использования; при большом трафике перейдите на собственного провайдера тайлов.
